# 📖 WeRead Clipper

> Chrome 浏览器插件，一键复制微信读书当前页所有文本内容。

## ✨ 功能

- **一键提取** — 点击插件图标，自动提取当前阅读页面的所有文本
- **智能识别** — 自动识别书籍名称和当前章节
- **页面预览** — 在阅读页面内直接预览提取的文本
- **快速复制** — 一键复制格式化文本到剪贴板
- **暗色模式** — 自动适配系统暗色模式

## 📦 安装

### 从源码安装（开发者模式）

1. 下载或克隆本仓库
   ```bash
   git clone https://github.com/bradenwu/weread-cliper.git
   ```

2. 打开 Chrome，进入扩展管理页面
   - 地址栏输入 `chrome://extensions/`
   - 或者菜单 → 更多工具 → 扩展程序

3. 开启「开发者模式」（右上角开关）

4. 点击「加载已解压的扩展程序」

5. 选择本项目文件夹

6. 插件安装完成！工具栏会出现 📖 图标

## 🚀 使用

1. 在 Chrome 中打开 [微信读书](https://weread.qq.com/web/reader/)
2. 进入任意一本书的阅读页面
3. 点击工具栏的 WeRead Clipper 图标
4. 插件会自动提取当前页面的文本内容
5. 点击「复制全部文本」即可复制到剪贴板

### 使用方式二：页面内预览

点击「页面内预览」按钮，会在阅读页面中弹出一个浮动面板，显示提取到的文本，可以直接预览和复制。

## 🛠️ 技术实现

- **Manifest V3** — 使用最新的 Chrome 扩展规范
- **Content Script** — 注入微信读书页面，提取 DOM 文本节点
- **Popup** — 清爽的弹出界面，展示提取结果和操作按钮

```
│   ├── icon48.png     # 48x48 图标
│   └── icon128.png    # 128x128 图标
└── README.md          # 说明文档
```

## ⚠️ 注意事项

- 本插件仅适用于微信读书网页版（`weread.qq.com`）
- 仅提取当前显示页面的文本，不会获取整本书内容
- 请遵守相关版权法律法规，合理使用提取的文本内容
