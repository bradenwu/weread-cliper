## 1. 项目背景

微信读书 Web 版可能使用 HTML5 Canvas 或高度混淆的页面结构渲染正文。常规 DOM 抓取、
运行态对象扫描和网络响应探测无法稳定获得完整章节文本。

WeRead Clipper 采用“所见即所得”的视觉截屏方案：自动滚动章节页面，逐屏截图，在浏览器
本地执行 OCR，并将相邻截图中的重叠文本自动去重拼接。

## 2. 产品目标

为需要摘录长篇阅读笔记的用户提供一键式章节文本提取能力：

- 无需手工翻页截图；
- 无需上传阅读内容到云端 OCR 服务；
- 自动处理截图重叠文本；
- 输出可复制、可预览、可导出的纯文本。

## 3. 目标用户

- 需要整理长篇摘录的研究人员；
- 需要制作学习资料的学生；
- 需要沉淀阅读笔记的重度阅读用户。

## 4. 核心使用场景

1. 用户在 Chrome 中打开微信读书章节阅读页。
2. 用户点击扩展图标，打开 WeRead Clipper。
3. 用户点击“开始提取当前章节”。
4. 扩展自动隐藏页面工具栏，从章节顶部开始逐屏截图并识别。
5. 扩展完成拼接后展示文本，用户复制、页面内预览或导出 TXT。

提取期间，用户需要保持目标微信读书标签页处于其所在 Chrome 窗口的活动标签状态；该窗口可置于系统后台，弹窗保持打开即可实时查看进度。

## 5. 功能需求

### 5.1 一键自动抓取

- 用户点击“开始提取当前章节”后启动任务。
- 自动隐藏顶部导航、底部工具栏、侧栏和较小的固定浮层。
- 自动记录原始滚动位置，并滚动到章节顶部。
- 按视口高度的 `78%` 逐屏向下滚动，保留适度截图重叠。
- 检测页面底部，确保底部最后一屏也被截图。
- 任务成功或失败后恢复被隐藏元素和原始滚动位置。

### 5.2 本地离线 OCR

- 使用 Tesseract.js 在扩展本地识别截图。
- 内置 `chi_sim` 简体中文模型和 WASM core。
- 运行时不得依赖外部 OCR API 或 CDN。
- OCR Worker 初始化后可在同一任务内复用。

### 5.3 智能文本去重与拼接

- 相邻截图之间存在重叠文本时，自动定位接缝。
- 容忍少量 OCR 错字、空格、换行和标点差异。
- 找不到可靠接缝时，不得静默丢失文本。
- 降级时在两段文本之间插入：

```text
[可能存在断层，需人工校对]
```

### 5.4 任务进度反馈

- 展示当前阶段：准备、截屏、识别、完成或失败。
- 展示当前处理屏数。
- 展示 OCR 进度和累计字数。
- Popup 关闭后任务继续执行；重新打开 Popup 后恢复任务状态。
- 浏览器重启、扩展重载或 service worker 意外中断后，下一次读取状态时尝试恢复原页面，并允许用户重新开始任务。

### 5.5 结果导出

- 在 Popup 文本框中展示格式化结果。
- 支持复制到剪贴板。
- 支持在阅读页内打开预览浮层。
- 支持导出 UTF-8 TXT 文件。

## 6. 非功能需求

### 6.1 隐私

- 阅读截图和 OCR 文本不得上传到外部服务。
- 除首次安装依赖和开发环境准备外，识别阶段支持完全离线运行。

### 6.2 性能

- 截图必须逐屏串行处理。
- OCR 完成后立即释放当前截图字符串。
- 不得在内存中累计整章 Base64 图片数组。
- 单任务最多处理 `80` 屏，避免滚动异常导致无限循环。

### 6.3 安全与合规

- 遵守 Chrome Manifest V3 CSP。
- Popup 和 Offscreen 页面不得使用内联 JavaScript。
- 仅处理用户有权使用的内容。

### 6.4 可维护性

- 产品需求、技术设计和实施日志分离维护。
- 核心拼接算法应独立于浏览器 API，可直接执行 Jest 单元测试。
- 扩展调度链路应具备 Playwright E2E 自动化验证。

## 7. 边界与非目标

当前版本不承诺：

- OCR 文本完全无错字；
- 图片章节、复杂公式、代码块和脚注均可完美识别；
- 在目标标签页被切换为非活动标签时继续截图；
- 自动处理超过 `80` 屏的异常超长章节；
- 自动上传、同步或发布提取结果。

## 8. 验收标准

### 8.1 自动化验收

```bash
npm run test:all
```

要求：

- Jest 单元测试全部通过；
- Playwright 扩展 E2E 全部通过；
- 本地中文模型和 WASM core 能在 MV3 CSP 下热启动；
- `git diff --check` 无格式问题。

### 8.2 发布前人工验收

在真实微信读书章节执行完整提取，记录：

1. 总屏数；
2. 总耗时；
3. 输出字数；
4. OCR 错字情况；
5. 人工校对接缝数量；
6. 浏览器内存峰值；
7. 页面 UI 和原始滚动位置是否恢复。
